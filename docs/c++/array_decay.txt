================================================================================
                    C++ 数组退化（Array Decay）与 C 风格字符串
================================================================================

--------------------------------------------------------------------------------
一、什么是退化（Decay）
--------------------------------------------------------------------------------

"退化"（decay）指数组类型在表达式中自动转换为指向首元素的指针。
这是 C 继承下来的隐式转换规则，C++ 完全保留。

    int arr[5] = {1, 2, 3, 4, 5};

    int* p = arr;   // arr 退化为 int*，指向 arr[0]
                    // 等价于 int* p = &arr[0];

退化后指针只保留地址，不再携带数组长度信息。

--------------------------------------------------------------------------------
二、何时发生退化
--------------------------------------------------------------------------------

2.1 传入函数参数时
------------------
函数形参中的数组声明会被编译器自动改写为指针：

    void f(int arr[5]);    // 编译器视为 void f(int* arr);
    void g(int arr[]);     // 同上，[] 内的数字被忽略

    int a[5];
    f(a);                  // a 退化为 int*，f 内无法知道长度为 5

这是 C++ 中数组退化最常见也最容易出错的场景。

2.2 赋值、初始化表达式
-----------------------
    int arr[3] = {1, 2, 3};
    int* p     = arr;          // 退化为 int*
    auto q     = arr;          // q 的类型是 int*，不是 int[3]

2.3 算术运算
------------
    int arr[5];
    int* p = arr + 2;          // arr 退化为 int*，再偏移 2，指向 arr[2]

2.4 传给 printf / std::cout 等变参函数
---------------------------------------
    int arr[5];
    printf("%p\n", arr);       // arr 退化为 void*（经过 int*）

--------------------------------------------------------------------------------
三、何时不发生退化
--------------------------------------------------------------------------------

3.1 sizeof
----------
    int arr[5];
    sizeof(arr);    // 返回 20（5 × sizeof(int)），不退化
    sizeof(int*);   // 返回 8（指针大小），若 arr 已退化则得此值

3.2 取地址 &arr
---------------
    int arr[5];
    &arr;           // 类型是 int(*)[5]（指向整个数组的指针），不是 int**
                    // &arr 和 arr 的值（地址）相同，但类型和步长不同：
    int(*pa)[5] = &arr;
    pa + 1;         // 跳过整个数组（20 字节），而非 4 字节

3.3 引用绑定
------------
    int arr[5];
    int (&ref)[5] = arr;   // ref 的类型是 int(&)[5]，保留了长度信息
    sizeof(ref);           // 返回 20，不退化

3.4 decltype
-------------
    int arr[5];
    decltype(arr) b;       // b 的类型是 int[5]，不是 int*

3.5 模板参数推导
----------------
    template<typename T, std::size_t N>
    void f(T (&arr)[N]) {  // 引用捕获，不退化，N 被推导为数组长度
        // sizeof(arr) == N * sizeof(T)
    }

    int a[5];
    f(a);   // T=int, N=5

    // 对比传值：
    template<typename T>
    void g(T arr) { ... }  // arr 推导为 int*，退化发生

--------------------------------------------------------------------------------
四、C 风格字符串与 char* 的退化
--------------------------------------------------------------------------------

4.1 字符串字面量的类型
-----------------------
    "hello"    // 类型是 const char[6]（含 '\0'），存储在只读段
               // 在表达式中退化为 const char*

    char arr[] = "hello";   // 类型是 char[6]，栈上可写副本
                            // 在表达式中退化为 char*

4.2 C 风格字符串的本质
-----------------------
C 风格字符串不是独立类型，而是一种约定：
  - 类型是 char* 或 const char*
  - 指向连续字节序列
  - 以 '\0'（NUL 字节）结尾，标记字符串结束

    char s[] = "hi";        // ['h']['i']['\0']，长度 3
    char* p  = s;           // p 指向 's' 的首字符 'h'
                            // p[0]='h', p[1]='i', p[2]='\0'

长度不在指针中，strlen / printf / stoi 等函数靠扫描 '\0' 确定结束位置。

4.3 argv 的结构
----------------
main 函数的 argv 是 char**：

    int main(int argc, char** argv)

内存布局（以 "./prog 12" 为例，argc=2）：

    argv ──→ [ argv[0] ]──→ "./prog\0"
             [ argv[1] ]──→ "12\0"
             [ argv[2] ]──→ NULL（哨兵）

  - argv      : char**，指针的指针
  - argv[i]   : char*，指向某个 C 风格字符串的首字符
  - argv[i][j]: char，第 i 个参数的第 j 个字符

    std::stoi(argv[1])   // stoi 接受 const char*，从首字符解析到 '\0' 为止

4.4 char* 不等于"单字符指针"
------------------------------
char* 的类型只说明"指向 char"，不说明后面有多少个字符：

    char  c = 'A';
    char* p = &c;       // 指向单个字符，后面无 '\0'，不是字符串
                        // 不能安全传给 printf("%s") 或 stoi

    char  s[] = "A";    // ['A']['\0']
    char* q   = s;      // 指向合法字符串，可安全传给字符串函数

类型相同（都是 char*），语义不同——是否为字符串取决于内存约定，
类型系统本身无法区分。

--------------------------------------------------------------------------------
五、多维数组的退化
--------------------------------------------------------------------------------

多维数组只有最外层退化为指针，内层维度保留：

    int a[3][4];
    // a 退化为 int(*)[4]（指向"含 4 个 int 的数组"的指针），而非 int**

    int (*p)[4] = a;    // 正确
    p + 1;              // 跳过 4 个 int（16 字节），指向 a[1]

    // int** 是错误的类型：
    // int** q = a;     // 编译错误

传给函数时同理：
    void f(int a[][4]);          // 等价于 void f(int (*a)[4]);
    void g(int a[3][4]);         // 同上，3 被忽略，等价于 void g(int (*a)[4]);

--------------------------------------------------------------------------------
六、常见陷阱
--------------------------------------------------------------------------------

陷阱 1：用 sizeof 测量"退化后的指针"
    void f(int arr[5]) {
        sizeof(arr);    // 返回 8（指针大小），不是 20（数组大小）
        // 需要额外传入 int n 或用模板引用
    }

陷阱 2：多维数组不能用 int** 接收
    int a[3][4];
    // int** p = a;     // 错误：int(*)[4] ≠ int**
    int (*p)[4] = a;    // 正确

陷阱 3：auto 推导丢失数组类型
    int arr[5];
    auto p = arr;       // p 是 int*，不是 int[5]
    auto& r = arr;      // r 是 int(&)[5]，保留类型

陷阱 4：字符串字面量赋给 char*（C++11 后废弃）
    char* p = "hello";          // 警告/错误：应用 const char*
    const char* q = "hello";    // 正确
