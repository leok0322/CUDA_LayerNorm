================================================================================
                    memset 初始化浮点数组：常见陷阱与正确做法
================================================================================

--------------------------------------------------------------------------------
一、memset 的本质
--------------------------------------------------------------------------------

memset(ptr, value, size) 按字节填充内存：
  - value 被截断为 unsigned char（1 字节）
  - 将这 1 字节的值重复填充到 size 个字节

因此 memset 只在填充值的每个字节相同时才能得到正确的浮点数。

--------------------------------------------------------------------------------
二、错误用法：用 memset 将 float 数组初始化为 1.0f
--------------------------------------------------------------------------------

  memset(weight, 1.f, sizeof(float) * N);   // 错误

执行过程：
  1.f 被截断为 unsigned char 值 1（0x01）
  每个 float 的 4 个字节均被填充为 0x01
  结果每个元素的二进制为 0x01010101
  对应浮点数为 2.3694e-38，不是 1.0f

--------------------------------------------------------------------------------
三、正确用法：只有填 0 时 memset 才适用于 float
--------------------------------------------------------------------------------

  memset(bias, 0, sizeof(float) * N);       // 正确

原因：
  0.0f 的 IEEE 754 二进制表示为 0x00000000，全部字节均为 0x00
  memset 以 0 填充每个字节后，结果恰好等于 0.0f

结论：memset 填充浮点数组，仅在值为 0 时结果正确。

--------------------------------------------------------------------------------
四、正确的初始化方式
--------------------------------------------------------------------------------

方式 1：循环赋值（最通用）

  for (int i = 0; i < N; i++) {
      weight[i] = 1.0f;
  }
  memset(bias, 0, sizeof(float) * N);       // 0.0f 可以继续用 memset

方式 2：std::fill（需要 #include <algorithm>，更简洁）

  std::fill(weight, weight + N, 1.0f);      // 初始化为 1.0f
  std::fill(bias,   bias   + N, 0.0f);      // 初始化为 0.0f

  注意：std::fill 的第二个参数是末尾指针，N 是元素个数，不是字节数。
  std::fill 按元素步进，步长由指针类型（float*）决定，编译器自动计算。

  与 memset 的单位区别：
    memset(bias, 0, sizeof(float) * N);      // 第三参数是字节数，须乘 sizeof(float)
    std::fill(bias, bias + N, 0.0f);         // 第二参数是末尾指针，只需元素个数

  实际使用示例：
    std::fill(weight, weight + max_size * max_size, 1.0f);
    std::fill(bias,   bias   + max_size * max_size, 0.0f);

方式 3：std::vector 的构造函数（使用容器时最推荐）

  std::vector<float> weight(N, 1.0f);       // 构造时直接指定初始值
  std::vector<float> bias(N, 0.0f);

--------------------------------------------------------------------------------
五、总结
--------------------------------------------------------------------------------

  操作                        是否正确   原因
  ──────────────────────────────────────────────────────────────────────
  memset(ptr, 0,   N*4)       正确       0x00000000 == 0.0f
  memset(ptr, 1.f, N*4)       错误       截断为 0x01，结果是 2.3694e-38
  memset(ptr, 0xFF, N*4)      错误       0xFFFFFFFF 是 NaN
  std::fill(ptr, ptr+N, val)  正确       逐元素赋值，适用任意浮点值
  循环逐元素赋值               正确       逐元素赋值，适用任意浮点值
