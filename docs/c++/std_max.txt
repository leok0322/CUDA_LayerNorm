================================================================================
                        std::max：用法、适用类型与模板推导
================================================================================

--------------------------------------------------------------------------------
一、头文件
--------------------------------------------------------------------------------

  #include <algorithm>

--------------------------------------------------------------------------------
二、函数模板定义
--------------------------------------------------------------------------------

  template<typename T>
  const T& max(const T& a, const T& b) {
      return (a < b) ? b : a;
  }

std::max 对所有支持 < 运算符的类型都适用。

--------------------------------------------------------------------------------
三、适用类型
--------------------------------------------------------------------------------

内置类型（直接可用）：

  std::max(1, 2);           // int
  std::max(1.0f, 2.0f);     // float
  std::max(1.0, 2.0);       // double
  std::max('a', 'b');       // char
  std::max(1u, 2u);         // unsigned int

自定义类型（需重载 < 运算符）：

  struct Point {
      int x;
      bool operator<(const Point& other) const { return x < other.x; }
  };
  std::max(Point{1}, Point{2});  // 可用，因为重载了 <

--------------------------------------------------------------------------------
四、为什么调用时不需要写 std::max<>()
--------------------------------------------------------------------------------

std::max<>() 和 std::max() 都可以调用，区别在于是否显式指定模板参数。

通常不需要写 <>，因为编译器可以通过参数类型自动推导模板参数（模板参数推导）。

模板参数推导完全由编译器在编译阶段完成，与代码本身的业务逻辑无关：
  - 推导发生在编译阶段，不产生任何运行时开销
  - 是 C++ 语言规范规定的编译器必须实现的行为，不是某个编译器的特殊优化
  - 所有符合 C++ 标准的编译器（GCC / Clang / MSVC）推导行为一致
  - 只需保证传入的两个参数类型一致，编译器自然推导出 T 是什么

推导过程示例（以 std::max(1, 2) 为例）：
  1. 编译器发现 std::max 是函数模板，需要确定 T 是什么
  2. 检查两个实参的类型：1 是 int，2 是 int
  3. 推导出 T = int
  4. 实例化 std::max<int>(const int&, const int&)


  std::max(1, 2);           // 编译器推导 T = int，等价于 std::max<int>(1, 2)
  std::max(1.0f, 2.0f);     // 编译器推导 T = float

需要显式写 <> 的情况：两个参数类型不同，编译器无法自动推导：

  std::max(1, 2.0);         // 编译错误：T 无法同时推导为 int 和 double
  std::max<double>(1, 2.0); // 正确：显式指定 T = double，int 自动转换

--------------------------------------------------------------------------------
五、调用方式对比
--------------------------------------------------------------------------------

  写法                    适用场景
  ──────────────────────────────────────────────────────────────────────
  std::max(a, b)          两个参数类型相同，让编译器自动推导（最常用）
  std::max<T>(a, b)       两个参数类型不同，或想明确指定类型

--------------------------------------------------------------------------------
六、常见陷阱：两个参数类型必须完全一致
--------------------------------------------------------------------------------

  std::max(1, 2.0);              // 编译错误：int 与 double 类型不同
  std::max(1, (int)2.0);         // 正确：显式转换为同一类型
  std::max<double>(1, 2.0);      // 正确：指定 T = double，int 隐式转换

在实际使用中，如 SIZE 容器元素取最大值：

  max_size = std::max(mSIZE[mSIZE.size() - 1], nSIZE[nSIZE.size() - 1]);
  // mSIZE 和 nSIZE 的元素类型须相同，否则需显式指定模板参数
