--------------------------------------------------------------------------------
一、函数签名
--------------------------------------------------------------------------------

  void __stcs(T* addr, T val);   // cache streaming
  void __stwb(T* addr, T val);   // write-back（默认 store 行为）
  void __stcg(T* addr, T val);   // cache global（绕过 L1，写 L2）
  void __stwt(T* addr, T val);   // write-through（直写 L2/DRAM）

  参数：
    addr ：目标地址，必须指向全局内存（cudaMalloc / __device__ 数组）
    val  ：写入值；类型 T 由 addr 的指针类型推导，支持 float/int/uint 等标量类型
  返回值：void（无返回）

  头文件：<cuda_runtime.h>（间接包含），设备端专用（__device__ 函数内调用）

--------------------------------------------------------------------------------
二、PTX 指令对应关系
--------------------------------------------------------------------------------

  ┌─────────────┬──────────────────────┬──────────────────────────────────────┐
  │ 函数        │ PTX 指令             │ L1 行为                              │
  ├─────────────┼──────────────────────┼──────────────────────────────────────┤
  │ 普通 store  │ st.global.f32        │ 写回（写入留在 L1，可被后续读命中）  │
  │ __stwb      │ st.global.wb.f32     │ 同上，显式写回                       │
  │ __stcg      │ st.global.cg.f32     │ 绕过 L1，写入 L2；L1 不缓存         │
  │ __stcs      │ st.global.cs.f32     │ 写入 L1 但快速逐出（streaming）      │
  │ __stwt      │ st.global.wt.f32     │ write-through，直写 L2/DRAM，不缓存  │
  └─────────────┴──────────────────────┴──────────────────────────────────────┘

  对应的 Load 变体（参考）：
    __ldca → ld.global.ca   缓存到 L1（默认）
    __ldcg → ld.global.cg   绕过 L1，只进 L2
    __ldcs → ld.global.cs   streaming load，L1 快速逐出
    __ldlu → ld.global.lu   last use，提示数据不再复用

--------------------------------------------------------------------------------
三、各变体适用场景
--------------------------------------------------------------------------------

  __stwb（写回，默认）：
    数据写入后仍会被本 kernel 或同 SM 的后续线程读取。
    例：写中间结果到 scratchpad，同一 block 内后续读取。

  __stcg（绕过 L1）：
    写入后不会被 L1 命中，强制走 L2。
    例：不同 SM 之间通信的标志位（flag），写完后由另一个 SM 的 __ldcg 读取。

  __stcs（streaming，本项目所用）：
    数据写完即不再使用，允许 L1 尽快逐出。
    防止一次性写入的数据长期占据 L1，挤走高复用数据（如 weight/bias）。
    例：写输出矩阵 out[]、写 mean[]、写 rstd[]——每个元素写一次后不再访问。

  __stwt（write-through）：
    完全不缓存，直写 DRAM。
    适合数据量极大且完全不复用的场景（如大规模 memcpy kernel）。
    通常比 __stcs 更激进，实际性能收益需具体测量。

--------------------------------------------------------------------------------
四、使用示例
--------------------------------------------------------------------------------

4.1 写输出数组（streaming store，本项目典型用法）
──────────────────────────────────────────────────
  // 归一化结果写回 out[]，每元素只写一次，不再读取
  // 使用 __stcs 防止 out[] 挤占 weight/bias 在 L1 中的位置
  for (int c = warp.thread_rank(); c < totalCol; c += warp.size()) {
    float n = rstd * (x[c] - mean);
    __stcs(out + row * totalCol + c, n * weight[c] + bias[c]);
  }

4.2 写 mean / rstd（仅 lane 0，streaming store）
─────────────────────────────────────────────────
  // mean/rstd 写完即不再使用，.cs hint 让 L1 快速回收该 cache line
  if (warp.thread_rank() == 0) {
    __stcs(mean + row, m);
    __stcs(rstd + row, s);
  }

4.3 与 __stcg 对比（跨 SM 通信标志位）
───────────────────────────────────────
  // SM A 写标志，SM B 用 __ldcg 读；两者都绕过 L1，保证可见性
  __stcg(flag + block_id, 1);          // 写方：绕过 L1 直接写 L2
  while (__ldcg(flag + dep_id) == 0);  // 读方：绕过 L1 从 L2 轮询

4.4 错误用法（类型不匹配）
───────────────────────────
  float* p = ...;
  __stcs(p, 1);        // ✗ val 是 int，addr 是 float*，类型不匹配，编译报错
  __stcs(p, 1.0f);     // ✓ val 是 float，与 float* 匹配

4.5 错误用法（第一参数传值而非指针）
──────────────────────────────────────
  __stcs(T* addr, T val) — 第一参数 addr 必须是指针，不能是解引用后的值。

  // ✗ 错误：mean[row] 是 scalar_t 值，不是指针；编译报错（类型不匹配）
  __stcs(mean[row], rowMean);
  __stcs(rstd[row], rowVar);

  // ✓ 正确：mean + row 是 scalar_t*，指向目标地址
  __stcs(mean + row, rowMean);
  __stcs(rstd + row, rowVar);

--------------------------------------------------------------------------------
五、对 L1 occupancy 的影响
--------------------------------------------------------------------------------

  L1 cache 容量有限（Ampere sm_86 默认 64 KB），写入策略影响其他数据的命中率：

  场景：LayerNorm kernel 同时访问 weight(C×4B)、bias(C×4B)、out(N×C×4B)
    - weight/bias：每行都要读，高复用，应当留在 L1
    - out：每元素只写一次，不复用，不应占用 L1

  使用普通 store 写 out：
    out 的 cache line 填满 L1，反复驱逐 weight/bias → weight/bias L1 miss 增加

  使用 __stcs 写 out：
    out 写后快速逐出，L1 空间留给 weight/bias → weight/bias 命中率更高
