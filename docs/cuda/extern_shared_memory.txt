================================================================================
  CUDA 动态共享内存（extern __shared__）说明
  ── 声明语法与地址规则
  ── 多个声明的陷阱
  ── 正确做法：单一声明 + 手动切分
  ── 两路 / 三路切分示例
================================================================================

--------------------------------------------------------------------------------
一、语法与地址规则
--------------------------------------------------------------------------------

  kernel 启动时通过 <<<grid, block, dynSmem>>> 分配一块连续动态 SMEM。
  kernel 内用 extern __shared__ 声明裸指针，指向该块的起始地址：

    extern __shared__ float smem[];   // smem == &动态SMEM[0]

  关键规则：
    所有 extern __shared__ 声明均指向 同一个 起始地址，与变量名无关。
    CUDA 编译器对 extern __shared__ 变量不做独立布局，只提供起始地址的视图。

--------------------------------------------------------------------------------
二、多个声明的陷阱（致命错误）
--------------------------------------------------------------------------------

  // ✗ 错误：两个变量指向同一起始地址，写 smemA 会覆盖 smem 的内容
  extern __shared__ __align__(16) scalar_t smem[];    // 起始地址 base
  extern __shared__ __align__(16) scalar_t smemA[];   // 同样是 base！

  外观上像两块独立内存，实际上完全重叠：
    smem   == smemA == &动态SMEM[0]

  后果：
    smemWeight / smemBias 通过 smem 写入的数据，
    会被通过 smemA 写入的数据原地覆盖，导致静默数据错误。

  编译器不会警告，运行时不会报错，结果直接出错。

--------------------------------------------------------------------------------
三、正确做法：单一 extern __shared__ + 手动切分
--------------------------------------------------------------------------------

  只声明一个 extern __shared__，用指针算术在其上建立多个分区：

    extern __shared__ __align__(16) scalar_t smem[];   // 唯一入口

    // 第一路：smemWeight，形状 [totalCol/4][5]
    scalar_t (*smemWeight)[5] = reinterpret_cast<scalar_t(*)[5]>(smem);

    // 第二路：smemBias，紧接 smemWeight 之后
    scalar_t (*smemBias)[5]   = smemWeight + totalCol / 4;
    //   偏移 = (totalCol/4) 个 scalar_t[5] 块 = (totalCol/4)*5*sizeof(scalar_t) 字节

    // 第三路：smemA，紧接 smemBias 之后，裸指针 + flat index
    scalar_t *smemA = reinterpret_cast<scalar_t*>(smemBias + totalCol / 4);
    //   flat index: [y][col][k] → y*(totalCol/4)*5 + col*5 + k

  内存布局（连续，无重叠）：
    ┌─────────────────────┬─────────────────────┬────────────────────────────────┐
    │ smemWeight          │ smemBias             │ smemA                          │
    │ [totalCol/4][5]     │ [totalCol/4][5]      │ [BSY][totalCol/4][5]           │
    └─────────────────────┴─────────────────────┴────────────────────────────────┘
    ↑ smem（base）         ↑ smemWeight+C/4       ↑ smemBias+C/4
    BSY = BLOCK_SIZE_Y_SMEM，C = totalCol

--------------------------------------------------------------------------------
四、dynSmem 字节数计算
--------------------------------------------------------------------------------

  两路切分（smemWeight + smemBias）：
    size_t dynSmem = sizeof(scalar_t) * 2 * (totalCol / 4) * 5;

  三路切分（+ smemA）：
    size_t dynSmem = sizeof(scalar_t) * (totalCol / 4) * 5 * (2 + BLOCK_SIZE_Y_SMEM);

  此值作为 <<<>>> 第三参数传入：
    kernel<<<grid, block, dynSmem>>>(args...);

--------------------------------------------------------------------------------
五、常见错误汇总
--------------------------------------------------------------------------------

  ① 多个 extern __shared__ 声明（本文重点）：
       extern __shared__ float smemWeight[];   // base
       extern __shared__ float smemBias[];     // 同样是 base，互相覆盖
       // ✓ 只保留一个，其余通过指针算术偏移

  ② 偏移单位错误（字节 vs 元素）：
       // ✗ 以字节为单位，但指针算术以元素为单位
       scalar_t (*smemBias)[5] = (scalar_t(*)[5])((char*)smemWeight + totalCol / 4);
       // ✓ 元素偏移（步长自动 × sizeof(scalar_t[5])）
       scalar_t (*smemBias)[5] = smemWeight + totalCol / 4;

  ③ 第三路忘记 reinterpret_cast，直接用数组指针偏移赋给裸指针：
       // ✗ 类型不匹配，编译报错
       scalar_t *smemA = smemBias + totalCol / 4;
       // ✓ reinterpret_cast 转换类型后再赋值
       scalar_t *smemA = reinterpret_cast<scalar_t*>(smemBias + totalCol / 4);

================================================================================
  统一extern __shared__ 为什么用 char 而不是 int 或模板类型
================================================================================

--------------------------------------------------------------------------------
一、问题背景
--------------------------------------------------------------------------------

  动态共享内存需要一个 extern __shared__ 声明作为基地址入口，
  该声明是翻译单元级符号，同一名称在整个翻译单元内只能有一种类型。

  模板 kernel 被 AT_DISPATCH_FLOATING_TYPES 实例化为 float 和 double 两个版本：

    // 实例1（scalar_t = float）
    extern __shared__ float smem[];

    // 实例2（scalar_t = double）
    extern __shared__ double smem[];   // ← 同名符号类型不同 → 编译报错

  解法：将声明类型固定为与模板无关的类型，再通过 reinterpret_cast 转换：

    extern __shared__ __align__(16) char smem_raw[];
    scalar_t (*smemWeight)[5] = reinterpret_cast<scalar_t(*)[5]>(smem_raw);

--------------------------------------------------------------------------------
二、为什么选 char，而不是 int 或 void
--------------------------------------------------------------------------------

  2.1 char：语义最准确
  ─────────────────────
    C++ 标准规定 sizeof(char) == 1（唯一保证为 1 的类型），
    char* 是"原始字节序列"的惯用表示，与 malloc/memcpy/memset 等
    底层内存操作的接口一致。
    声明为 char[] 清楚地表达"这是一块未类型化的字节缓冲区"。

  2.2 char：对齐要求最宽松
  ─────────────────────────
    char 的对齐要求是 1 字节（alignof(char) == 1），
    不会对后续 reinterpret_cast 的目标类型施加额外约束。
    实际对齐由 __align__(16) 属性保证，职责单一，不依赖 char 本身的对齐。

    对比 int（alignof = 4）：
      若去掉 __align__(16)，int[] 的 4 字节对齐对 double（需 8 字节）仍不足，
      可能产生未定义行为；char[] 的 1 字节对齐则让对齐完全由 __align__ 控制。

  2.3 不能用 void
  ────────────────
    void[] 在 C++ 中不合法：void 不是完整类型，不能声明数组。
    reinterpret_cast 也无法从 void[] 出发。

  2.4 int / unsigned char / uint8_t 也可以，但有缺点
  ────────────────────────────────────────────────────
    ┌──────────────┬────────────────────────────────────────────────────────┐
    │ 类型         │ 说明                                                   │
    ├──────────────┼────────────────────────────────────────────────────────┤
    │ char         │ ✓ 推荐。sizeof=1，语义明确，对齐要求最低               │
    │ unsigned char│ ✓ 可用。与 char 等价，部分场景避免符号位歧义           │
    │ uint8_t      │ ✓ 可用。明确 8-bit，但需要 <cstdint>，略显冗余        │
    │ int          │ △ 可编译，但 sizeof=4，语义暗示"存整数"，有误导性      │
    │ float        │ △ 可编译，但 sizeof=4，且暗示"存浮点"，语义错误        │
    │ void         │ ✗ 非法，void 不是完整类型，不能声明数组               │
    └──────────────┴────────────────────────────────────────────────────────┘

--------------------------------------------------------------------------------
三、完整用法示例
--------------------------------------------------------------------------------

  // 声明：char 固定类型，避免模板实例化冲突
  extern __shared__ __align__(16) char smem_raw[];

  // 转换：reinterpret_cast 到目标类型，不涉及任何数据移动
  scalar_t (*smemWeight)[5] = reinterpret_cast<scalar_t(*)[5]>(smem_raw);
  scalar_t (*smemBias)[5]   = smemWeight + totalCol / 4;
  scalar_t  *smemA          = reinterpret_cast<scalar_t*>(smemBias + totalCol / 4);

  // __align__(16) 保证 smem_raw 基地址 16 字节对齐，
  // 使 float4 / double2 等向量类型的访问满足对齐要求
